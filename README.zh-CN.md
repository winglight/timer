# Timer

一款基于浏览器的呼吸练习计时器，提供粒子呼吸引导、练习记录、可选云同步、沉浸式动态场景和自然环境声音。

## 在线演示

https://timer.broyustudio.com/

## 功能

- 自定义吸气、呼气、停留时间和练习总时长
- 呼吸圆环与细腻粒子日冕视觉引导
- 支持减少动态效果、呼吸阶段提示音、暂停/继续、提前结束保存和屏幕唤醒锁
- 练习日历、月度统计、连续练习天数、每日目标、记录详情和 JSON 导出
- 生成高清练习快照并分享到 X
- 浏览器本地持久化，并兼容旧版 breath_settings / breath_history 数据
- 可选 Cloudflare R2 设置与练习记录同步
- 十一种环境场景：日落湖畔、海浪与晚霞、云海山顶、细雨林中小屋、森林晨雾、静谧溪谷、星空夜色、樱花微风、沙漠暮色、木屋中的火炉、空间站 · 地球
- 十一个场景均使用 three.js：水纹与倒影、云海、细雨、林间小动物、花枝、瀑布、星空、风沙，以及火焰与室内联动光影、明显转动的地球、变化的昼夜分界线、动态仪表与模拟海洋气旋
- 打开页面后及呼吸练习期间均可运行，可独立关闭背景
- 七种真实自然录音：海浪、轻柔雨声、清晨鸟鸣、森林环境声、溪流、篝火和微风，不用随机噪声模拟自然声音
- 场景和声音使用独立的一层菜单；支持音量调节和偏好记忆。打开页面后尝试自动恢复已启用的声音，浏览器拦截时在首次交互后接续播放
- 中英文界面，适配桌面和移动端

## 项目结构

项目使用原生 HTML、CSS 和 JavaScript。

- index.html — 页面结构
- engine.js — 呼吸计时模型
- corona.js — 粒子日冕渲染
- app.js — 页面交互、练习记录、提示音、日历和同步
- ambient.js — 场景偏好、自然录音播放与自动恢复
- scene-runtime.js — 按需加载的共享 WebGL 渲染器、场景切换与生命周期
- scenes/ocean.js — 不规则波面、原图浪花与夕阳反射
- scenes/lake.js — 对齐摄影岸线的波面网格与山色倒影
- scenes/clouds.js — 保留摄影细纹的云层平移、起伏与山脊遮挡
- scenes/weather.js — 保持原参数的林中小屋雨景
- scenes/woodland.js — 林间小动物、薄雾与真实花枝的风动形变
- scenes/waterfall.js — 对齐水流区域的瀑布输运、水面折射和池面涟漪
- scenes/landscape.js — 真实星图与峡谷云层移动、贴地风沙和远处热气
- scenes/hearth.js — 写实火舌形变、室内火光和柔和阴影边界晃动
- scenes/orbital.js — 写实空间站舷窗、动态仪表、地球、大气边缘、星空和模拟海洋气旋
- scenes/orbital-model.js — 系统时间驱动的加速自转、太阳光照变化、可复现的海洋气旋与响应式球体构图
- vendor/ — 本地托管的 three.js 0.187.0 与 MIT 许可证
- assets/scenes/ — 同源场景照片及来源说明
- share.js — 练习快照生成与分享
- styles.css — 视觉样式、环境场景和响应式布局

## 声音恢复与动态背景

选择一种环境声音后，页面会记住录音和音量，下次打开时尝试自动播放。如果浏览器要求用户交互，声音菜单会显示“点击播放”，点击、触摸页面或按键即可重试。自动播放被拦截与录音加载失败会分别显示状态。主动暂停录音或选择“关闭声音”也会保存，刷新后保持安静。

海浪与晚霞参考湖畔的摄影反射方式，以不规则、接近同一风向的波面带动原图泡沫与水纹，波面法线响应照片中的夕阳光线，替换原来交叉排列的波纹和程序天空。已经认可的日落湖畔与细雨小屋保留现有渲染参数。

云海使用 2400 像素原图，真实云脊与细纹随连续流场平移、起伏；移除了灰暗的体积噪声层，提亮云区并减轻本场景的暗色遮罩，山体和天空保持固定。樱花让照片中前景花枝及花簇围绕支点弯动，取消原先主体静止、仅掉落花瓣的处理。森林小动物沿林地活动并贴着树干攀爬，薄雾作为次要动态。

溪谷在原图水流遮罩内连续向下输运纹理，并带动池面涟漪，岩石和植被固定。星空让真实星图缓慢转动、原图星点轻微闪烁，山体剪影固定。沙漠让照片中的云层漂移，增加贴地沙流和远处轻微热气，岩壁保持稳定。这些是摄影 2.5D 动态与水面几何，不是完整的流体或大气模拟。

十一个场景共享一个 WebGL 渲染器和一条动画循环，目标帧率 30 fps，旧版 Canvas 叠加特效已移除。水面使用更高绘制预算来表现倒影，其余细节场景使用独立上限：

| 场景 | 像素密度上限 | 绘制面积上限 |
| --- | ---: | ---: |
| 海浪、日落湖畔 | 2 | 800 万像素 |
| 云海、森林、樱花、瀑布、星空、沙漠、空间站 | 2 | 400 万像素 |
| 木屋火炉（体积火焰） | 1.5 | 200 万像素 |
| 细雨小屋 | 1.25 | 120 万像素 |

像素密度不会超过设备自身的像素比。例如高密度手机上的 390 × 844 视口，水面现在绘制为 780 × 1688 像素。切换精度时复用同一个渲染器，切回小屋恢复原预算。这些是资源分配上限，不代表已测得的手机帧率或耗电表现。

动态无需先开始呼吸练习。关闭背景、页面挂起或开启系统“减少动态效果”后停止动画。模块或纹理加载失败、着色器错误、WebGL 上下文丢失时显示静态照片；切换场景会丢弃过期异步结果并释放旧 GPU 资源。计时器和独立背景音仍可使用。

测试覆盖场景路由、异步加载竞争、暂停时钟、失败回退和 GPU 资源释放。画面还需检查实际着色器与几何输出，不能仅用像素变化量判断自然度。手机浏览器的持续性能和耗电需要真机检查。

## 木屋火炉与空间站地球

**木屋中的火炉**使用带有较小劈柴、自然旺盛火苗的写实底图。多簇火舌分别摆动、上升并改变高度，木柴、家具和石材保持原来的形状；不规则火光带动附近石壁、木墙和地板的明显明暗变化，以及柔和阴影边界的晃动。动态渲染通过 `data-scene-texture` 使用原始照片，减少动态效果或 WebGL 不可用时则显示独立的完整静态画面。

**空间站 · 地球**在明亮的白色写实舱室中展示完整地球。自转速度改为真实恒星日速度的 **240 倍，约 359 秒转一圈**，正常观看几秒即可看到移动；太阳光照采用独立的 210 秒周期，让昼夜分界线也随之变化。舱内屏幕显示变化的遥测读数、滚动曲线和状态指示。自转与光照仍由系统时钟驱动，切换场景或从后台返回不会重置；手机竖屏也保留完整球体和周围舱室。这是加速的艺术化观景效果，不是实时轨道或天文模拟。

海洋气旋是具有随机位置、大小、生命周期的可复现视觉模拟，南北半球采用相反的旋转方向，演化时间压缩为数分钟，不对应实时天气。横屏和竖屏分别提供静态画面，关闭动态时仍能保留完整地球。场景与环境声继续独立选择，火炉可搭配现有的“篝火轻响”。

新增素材随应用同源托管。[素材来源说明](assets/scenes/new-scenes.md)记录了生成木屋的提示词和地球影像来源。
